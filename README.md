# make-knowledge-cards

`make-knowledge-cards` 是一个可开源的 Codex Skill，用于把用户粘贴的文章或本地 Markdown/TXT 文件提炼成结构清晰、便于复习的知识卡片。

## 项目解决什么问题

普通摘要容易混合多个观点、保留重复内容，或者补充原文没有的信息。本项目从原文中筛选真正重要且可独立理解的知识点，将其整理成通常 5～8 张卡片；如果文章信息不足，则减少卡片数量，不为凑数拆分或编造内容。

## 主要功能

- 支持直接粘贴文章，以及读取本地 `.md`、`.txt` 文件。
- 优先提取定义、机制、因果关系、方法、关键区别和结论。
- 保证一张卡片只讲一个知识点，并合并重复或高度重叠的内容。
- 所有事实均以输入文章为依据，保留原文中的适用范围、限定条件和不确定性。
- 每张卡片包含标题、核心知识、简明解释、例子或自测问题。
- 默认使用原文语言输出，也可由用户指定其他语言。

当前不支持网页抓取、PDF、Anki 导出和图形界面。

## 安装方法

本项目没有运行时脚本或第三方依赖，但需要支持 Skills 的 Codex 环境。

1. 下载本项目或取得项目文件。
2. 将整个 `skills/make-knowledge-cards` 目录复制到 Codex 的用户 Skill 目录：
   - 设置了 `CODEX_HOME` 时：`$CODEX_HOME/skills/make-knowledge-cards`
   - 未设置时，通常为 `~/.codex/skills/make-knowledge-cards`
   - Windows 默认路径通常为 `%USERPROFILE%\.codex\skills\make-knowledge-cards`
3. 开始一个新的 Codex 会话，让 Codex 重新发现该 Skill。

安装后目录至少应包含：

```text
make-knowledge-cards/
├── SKILL.md
└── agents/
    └── openai.yaml
```

## 使用方法

直接粘贴文章：

```text
$make-knowledge-cards 请把下面的文章转换成知识卡片：
<粘贴文章正文>
```

读取本地文件：

```text
$make-knowledge-cards 请把 D:\notes\article.md 转换成知识卡片。
```

指定输出语言：

```text
$make-knowledge-cards 请读取 D:\notes\article.txt，并用英文生成知识卡片。
```

## 输入输出示例

输入：

```text
可靠的重试只应用于临时故障。连续立即重试会增加故障服务的负载。指数退避会逐次延长重试前的等待时间。随机抖动可以避免多个客户端同时重试。重试策略还应设置最大次数或总时限。
```

输出：

```markdown
### 1. 重试只适用于临时故障

- **核心知识：** 可靠的重试只应用于临时故障。
- **简明解释：** 重试策略首先需要判断故障是否具有临时性。
- **例子或自测问题：** 什么类型的故障适合使用重试？

### 2. 连续立即重试会增加服务负载

- **核心知识：** 在服务发生故障时连续立即重试，会进一步增加其负载。
- **简明解释：** 没有等待间隔的重复请求会给故障服务带来更多压力。
- **例子或自测问题：** 为什么不应连续立即重试？

### 3. 指数退避逐步延长等待时间

- **核心知识：** 指数退避会在每次失败后延长下一次重试前的等待时间。
- **简明解释：** 它通过逐次增加等待时间来控制重试频率。
- **例子或自测问题：** 指数退避会如何改变重试间隔？

### 4. 随机抖动避免客户端同时重试

- **核心知识：** 随机抖动可以错开多个客户端的重试时间。
- **简明解释：** 为等待时间加入随机变化，可以减少客户端在同一时刻再次发起请求的情况。
- **例子或自测问题：** 随机抖动主要解决什么问题？

### 5. 重试策略必须设置停止条件

- **核心知识：** 重试策略应设置最大重试次数或总时间限制。
- **简明解释：** 明确的停止条件可以防止重试无限持续。
- **例子或自测问题：** 原文提出了哪两种重试停止条件？
```

输出措辞可能随文章内容变化，但每张卡片都会保持上述四项结构，并且只使用输入材料能够支持的信息。
